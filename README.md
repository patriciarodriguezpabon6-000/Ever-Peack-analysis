# EverPeak Analysis

Este repositorio contiene el análisis de datos desarrollado durante el **Sprint 6 del caso EverPeak–SilverBasket**.

El proyecto utiliza el dataset `everpeak_retail`, compuesto por **2.000 órdenes de clientes**, diseñado para simular un escenario real de datos de retail. El conjunto presenta diferentes situaciones de calidad de datos, como **valores faltantes, valores sentinela, datos atípicos (outliers) y registros inconsistentes**.

## 🎯 Objetivo del proyecto

Realizar un proceso de exploración y análisis de los datos para identificar problemas de calidad, realizar la limpieza necesaria y obtener información útil para comprender el comportamiento de las ventas y los clientes.

## 🔎 Proceso de análisis

Durante el proyecto se trabajó en las siguientes etapas:

* Exploración inicial del dataset.
* Identificación de valores faltantes y valores sentinela.
* Detección y análisis de outliers.
* Limpieza y preparación de los datos.
* Análisis descriptivo de las variables.
* Identificación de patrones y comportamientos relevantes.
* Obtención de conclusiones a partir de los datos.
